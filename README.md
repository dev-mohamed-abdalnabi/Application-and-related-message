# الهاتف — تطبيق مكالمات ورسائل وجهات اتصال (أندرويد)

تطبيق Kotlin + Jetpack Compose بتصميم Material 3 Expressive (RTL، خط Tajawal).

## المميزات
- **مكالمات**: لوحة أرقام، سجل مكالمات (فائتة/واردة/صادرة)، شاشة مكالمة كاملة (رد/رفض/رفض برسالة/كتم/سماعة/بلوتوث/تعليق/إضافة مكالمة/دمج/DTMF)، اختيار الشريحة، حساس القرب، إشعارات.
- **جهات الاتصال**: بحث، مفضلة، تفاصيل، إضافة/تعديل/حذف، حظر.
- **الرسائل SMS**: محادثات، إرسال/استقبال، رد سريع من الإشعار، حذف، إشعارات.
- **تطبيق افتراضي**: يقدر يبقى تطبيق الاتصال والرسائل الافتراضي.
- **إعدادات**: ثيم (تلقائي/فاتح/داكن/AMOLED)، ألوان مميزة، الأرقام المحظورة.

## البناء التلقائي
أي `git push` بيشغّل `.github/workflows/build.yml` اللي بيبني `Phone.apk`:
- من تبويب **Actions** ← آخر تشغيل ← Artifacts ← `Phone-APK`
- أو من تبويب **Releases** (بيتعمل Release جديد مع كل push).

## ملاحظات
- مفتاح التوقيع (`app/phone-release.jks`) ثابت عشان التحديثات تتثبت فوق القديم. للنشر على Google Play بدّله بمفتاحك.
- MMS (الصور في الرسائل) غير معروضة حاليًا.
- محلي: `python3 assemble.py` ثم نزّل خط Tajawal في `app/src/main/res/font` (tajawal_regular/medium/bold/extrabold.ttf) ثم `gradle :app:assembleRelease`.
- كل الملفات في الجذر (مسطّحة) عشان الرفع من الموبايل؛ `assemble.py` بيرتّبها وقت البناء.
